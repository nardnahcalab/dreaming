Simple Example

Without Dreaming:

  • You: "I'm vegetarian"
  • AI: "Here are restaurants..." (includes meat)
  • You: "But I told you I'm vegetarian!"

With Dreaming:

  • You: "I'm vegetarian" (Week 1)
  • ...AI processes this in background...
  • You: "Recommend restaurants" (Week 4)
  • AI: "Based on your vegetarian preference..."

🏗️ Two Architectures

🟢 OpenAI

Rewrites in place

  • Updates same memory store
  • Each pass builds on previous
  • No rollback capability
  • More aggressive approach

🟠 Anthropic

Parallel artifact

  • Never modifies original
  • Creates new memory store
  • Can rollback if needed
  • More cautious approach

Key Differences

Feature OpenAI Anthropic
Store ID Same (rewritten) Different (new)
Original Store Overwritten Preserved
Rollback ❌ Not possible ✅ Possible
Risk Level Higher Lower

⚠️ Important

Anthropic's approach is safer because you can always revert to the original if the dream doesn't help. This is recommended for production systems.

🔬 Research & Risks

⚠️ Zhang's Paper (May 2026)

When AI rewrites its own memory repeatedly, it can forget things it once knew.

Three Failure Modes

1. Misgrouping

Different things merge together

"Asked about Python" + "Asked about JavaScript" → merged

2. Interference

Context gets lost

"When using Python, use list comprehensions" → "use list comprehensions"

3. Overfit

Specific details get lost

"When user is vegetarian" → deleted

✅ The Solution

Use episodic memory (keep raw transcripts) instead of abstract memory (compressed summaries). This is why Anthropic's approach of preserving the original is safer.
